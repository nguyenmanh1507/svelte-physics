Maneuver đặc biệt

X Split-S — 1 phím: lật ngửa rồi kéo, quay 180° bổ nhào. Từ chối nếu không đủ độ cao.
C Immelmann — 1 phím: kéo nửa vòng lên rồi lật lại, quay 180° lấy độ cao.
AA / DD Barrel roll né tên lửa — double-tap.
Shift+W/S+Space High-G turn — giữ Shift+Space khi đang pitch: quay gắt hơn, mất tốc nhanh.
Shift+Space → S Post-Stall (PSM) — tổ hợp: thả hết cần, bấm Shift+Space cùng lúc (≤90 ms) → "PSM READY" → kéo S = Cobra. Tiếp tục giữ S ≥ 0,7 s = Kulbit. S+A/D = Herbst/J-turn. Cần 250–450 km/h.
V → S Cách 1 phím để vào PSM READY (thay cho tổ hợp).
W giữ mạnh Huỷ maneuver đang chạy.

Gamepad

Cần trái: pitch/roll · RT boost · LT phanh · LB/RB yaw (double-tap = barrel roll) · LT+RT với cần trung tính = PSM · A = PSM · X = Split-S · Y = Immelmann · Back = đổi chế độ · Start = hồi sinh.

Mẹo

Phanh xuống ~350 km/h ở độ cao > 500 m để thử Cobra/Kulbit. Tiêm kích có corner speed khoảng 650 km/h, đó là lúc quay nhanh nhất. Thử đổi sang máy bay vận tải để cảm nhận quán tính lớn.

Config máy bay (JSON, data-driven)

Cùng một lõi stepFlight() chạy mọi loại máy bay: chỉ khác file config. Đơn vị: m/s, deg/s, rate là curve [[tốc độ, deg/s], …]. Bỏ một khoá trong maneuvers để tắt maneuver đó.

Arcade Plane Controller

Prototype Three.js cho lõi bay engine-agnostic: rate-command + G-limit + AoA-limit, 3 chế độ điều khiển (Mouse-aim / Standard / Expert), 3 config máy bay và hệ thống maneuver dạng state machine (Cobra, Kulbit, Herbst, Split-S, Immelmann, High-G, Barrel roll).

Bay qua các vòng xanh để luyện tập. Bấm H xem phím, P chỉnh config trực tiếp.

Trên màn hình cảm ứng: cần ảo bên trái, nút maneuver bên phải (chế độ Standard).
